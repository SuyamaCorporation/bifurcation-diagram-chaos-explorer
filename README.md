# Bifurcation Diagram Chaos Explorer

Plots the logistic map bifurcation diagram showing the onset of chaos through period-doubling; adjustable r-range sliders let you zoom into the fractal period-doubling structure.
Features Feigenbaum reference lines (δ ≈ 4.6692), four color modes (period, classic, cyan, fire), drag-to-zoom on canvas, r/x coordinate tooltip, and PNG export.
